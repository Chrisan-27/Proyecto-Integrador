# PUCE Parking

Proyecto integrador desarrollado para PUCE TEC.

PUCE Parking es una página web que permite estimar la disponibilidad de espacios en el Parqueadero H de la PUCE según la hora, el tipo de vehículo y la preferencia de estacionamiento.

## Tecnologías utilizadas

- HTML
- CSS
- JavaScript
- Python

## Funcionamiento

El usuario ingresa:

- Hora
- Tipo de vehículo
- Preferencia de estacionamiento

El sistema calcula una disponibilidad estimada y recomienda una zona del parqueadero.

## Importante

El proyecto utiliza datos simulados para realizar las estimaciones y no representa disponibilidad en tiempo real.
